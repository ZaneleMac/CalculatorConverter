# C# Console CalculatorConvetor Application

A beginner-friendly, robust console application built in C# that performs basic arithmetic calculations, unit conversions, and custom currency exchanges with strict input validation to prevent runtime crashes.

## Features
- **Basic Arithmetic:** Addition, subtraction, multiplication, and division with division-by-zero protection.
- **Distance Conversion:** Seamless conversion between Kilometers and Miles.
- **Temperature Conversion:** Conversion between Celsius and Fahrenheit scales.
- **Currency Conversion:** Custom conversion from Ghanaian Cedis (GHS) to US Dollars (USD) using a user-defined exchange rate.
- **Error Handling:** Utilizes `double.TryParse` validation loops to gracefully handle incorrect text inputs without crashing.

## Prerequisites
- [.NET SDK](https://dotnet.microsoft.com/download) installed on your machine.
- Visual Studio 2022/2026 Community.
